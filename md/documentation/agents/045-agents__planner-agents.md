# 规划器智能体

Beta

此功能属于测试版模块（`1.3.0-beta`）。API 可能会在未来的版本中发生变化。
详情请参阅[模块版本管理](../../module-versioning/)。

规划器智能体是通过迭代规划周期来规划和执行多步骤任务的 AI 智能体。
它们持续构建或更新计划、执行步骤，并根据当前状态检查完成条件。

规划器智能体适用于复杂任务，
这些任务需要将高层目标分解为更小、可操作的步骤，
并根据每个步骤的结果调整计划。

在使用[基于图的智能体](../graph-based-agents/)时，你需要定义所有节点和边，
而对于规划器智能体，你只需定义具有类型化输入和输出的动作（节点）。
规划器会创建合理的边，以适合实现期望的状态，
并且它还可以更新步骤之间的最优路径。
这允许一种更动态的方法，可能更强大，
但与基于图的智能体相比，可控性较低。

规划器智能体通过迭代规划周期运行：

1. 规划器根据当前状态创建或更新计划。
2. 规划器执行计划中的单个步骤，更新状态。
3. 规划器根据当前状态判断计划是否完成。
   - 如果计划已完成，则周期结束。
   - 如果计划未完成，则从第一步重复该周期。

```
graph LR
  A[Create or update plan] --> B["Execute step and update state"]
  B --> C["Check completion"]
  C -->|Completed| D[[Done]]
  C -->|"Not completed"| A
```

Koog 提供两种类型的规划器智能体：

- [基于 LLM 的规划器](llm-based-planners/) 使用 LLM 创建和更新计划
- [GOAP 智能体](goap-agents/) 使用特殊算法来确定最优动作序列
