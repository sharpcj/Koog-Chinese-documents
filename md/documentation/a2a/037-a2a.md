本页概述了 Koog agentic 框架中 A2A（Agent-to-Agent）协议的实现。

## 什么是 A2A 协议？

A2A（Agent-to-Agent）协议是一种标准化通信协议，使 AI agent 能够彼此交互并与客户端应用程序交互。
它定义了一组方法、消息格式和行为，用于实现一致且可互操作的 agent 通信。
有关 A2A 协议的更多信息和详细规范，请参阅官方 [A2A Protocol 网站](https://a2a-protocol.org/latest/)。

## 入门

**重要**：A2A 依赖项默认**不**包含在 `koog-agents` 元依赖中。
你必须显式地将所需的 A2A 模块添加到项目中。

要在项目中使用 A2A，请根据你的使用场景添加依赖项：

- **用于 A2A client**：请参阅 [A2A Client 文档](a2a-client/#dependencies)
- **用于 A2A server**：请参阅 [A2A Server 文档](a2a-server/#dependencies)
- **用于 Koog 集成**：请参阅 [A2A Koog Integration 文档](a2a-koog-integration/#dependencies)

## 关键 A2A 组件

Koog 为 client 和 server 提供了 A2A protocol v0.3.0 的完整实现，并提供了与 Koog agent 框架的集成：

- [A2A Server](a2a-server/) 是一个 agent 或 agentic 系统，它暴露实现 A2A 协议的端点。它接收来自客户端的请求、处理任务，并返回结果或状态更新。它也可以独立于 Koog agents 使用。
- [A2A Client](a2a-client/) 是使用 A2A 协议与 A2A server 发起通信的客户端应用程序或 agent。它也可以独立于 Koog agents 使用。
- [A2A Koog Integration](a2a-koog-integration/) 是一组类和实用工具，用于简化 A2A 与 Koog Agents 的集成。它包含用于在 Koog 框架内实现无缝 A2A agent 连接和通信的组件（A2A features 和 nodes）。
