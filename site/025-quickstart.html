快速开始

本指南将帮助你开始在项目中使用 Koog。

前置条件

确保你的环境和项目满足以下要求：

  • JDK 17+
  • Kotlin 2.2.0+
  • Gradle 8.0+ 或 Maven 3.8+

安装 Koog

将 Koog package 添加为依赖：

Gradle (Kotlin)Gradle (Groovy)Maven

build.gradle.kts

dependencies {
    // Stable
    implementation("ai.koog:koog-agents:1.3.0")

    // Beta
    implementation("ai.koog:koog-agents-additions:1.3.0-beta")
}

build.gradle

dependencies {
    // Stable
    implementation 'ai.koog:koog-agents:1.3.0'

    // Beta
    implementation 'ai.koog:koog-agents-additions:1.3.0-beta'
}

pom.xml

<dependency>
    <!-- Stable -->
    <dependency>
        <groupId>ai.koog</groupId>
        <artifactId>koog-agents-jvm</artifactId>
        <version>1.3.0</version>
    </dependency>

    <!-- Beta -->
    <dependency>
        <groupId>ai.koog</groupId>
        <artifactId>koog-agents-additions-jvm</artifactId>
        <version>1.3.0-beta</version>
    </dependency>
</dependency>

模块版本管理

Koog 遵循语义化版本（X.Y.Z）。稳定模块（例如 1.0.0）具有受保证的 API， 而 beta 模块（例如 1.0.0-beta）是实验性的，可能会在版本之间发生变化。

详情请参阅模块版本管理。

Nightly builds

develop 分支的 nightly builds 会发布到 JetBrains Grazie Maven 仓库。

要使用 nightly build，请将以下仓库添加到你的构建配置： https://packages.jetbrains.team/maven/p/grazi/grazie-platform-public.

然后将你的 Koog 依赖更新为所需的 nightly 版本。Nightly 版本遵循以下模式： [next-major-version]-develop-[date]-[time]。

你可以在这里浏览可用的 nightly builds。

设置 API key

Koog 需要来自受支持的 LLM provider 的 API key，或本地运行的 LLM。

Warning

避免在源代码中硬编码 API keys。 使用环境变量来存储 API keys。

OpenAIAnthropicGoogle βDeepSeek βOpenRouterBedrockMistral βOllama

获取你的 OpenAI API key，并将其分配给 OPENAI_API_KEY 环境变量。

Linux/macOSWindows

export OPENAI_API_KEY=your-api-key

setx OPENAI_API_KEY "your-api-key"

创建你的第一个 Koog agent

OpenAIAnthropicGoogle βDeepSeek βOpenRouterBedrockMistral βOllama

以下示例通过 OpenAI API，使用 GPT-4o 模型创建并运行一个简单的 Koog agent。

KotlinJava

fun main() = runBlocking {
    // Get the OpenAI API key from the OPENAI_API_KEY environment variable
    val apiKey = System.getenv("OPENAI_API_KEY")
        ?: error("The API key is not set.")

    // Create an agent
    val agent = AIAgent(
        promptExecutor = MultiLLMPromptExecutor(OpenAILLMClient(apiKey)),
        llmModel = OpenAIModels.Chat.GPT4o
    )

    // Run the agent
    val result = agent.run("Hello! How can you help me?")
    println(result)
}

// Get the OpenAI API key from the OPENAI_API_KEY environment variable
String apiKey = System.getenv("OPENAI_API_KEY");
if (apiKey == null) {
    throw new RuntimeException("The API key is not set.");
}

// Create an agent
AIAgent<String, String> agent = AIAgent.builder()
    .promptExecutor(new MultiLLMPromptExecutor(openAIClient(apiKey)))
    .llmModel(OpenAIModels.Chat.GPT4o)
    .build();

// Run the agent
String result = agent.run("Hello! How can you help me?");
System.out.println(result);

该示例可能产生以下输出：

Hello! I'm here to help you with whatever you need. Here are just a few things I can do:

- Answer questions.
- Explain concepts or topics you're curious about.
- Provide step-by-step instructions for tasks.
- Offer advice, notes, or ideas.
- Help with research or summarize complex material.
- Write or edit text, emails, or other documents.
- Brainstorm creative projects or solutions.
- Solve problems or calculations.

Let me know what you need help with—I’m here for you!
